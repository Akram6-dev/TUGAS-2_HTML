Tentang Coding Club

Coding Club berkomitmen memperkenalkan dunia pemrograman dan teknologi digital kepada anggotanya. Klub ini bertujuan membangun fondasi berpikir komputasional, mengasah kemampuan pemecahan masalah (problem solving), serta menumbuhkan kreativitas melalui pembuatan perangkat lunak.

Manfaat bergabung dengan klub ini adalah penguasaan keterampilan teknis (coding) yang relevan dengan masa depan. Selain itu, Anda juga dapat melatih kerja sama tim, berkomunikasi dengan baik, serta memperluas jejaring pertemanan yang suportif.

Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek

Kegiatan 1: Belajar HTML

Mempelajari dasar-dasar HTML untuk membuat struktur halaman website.

Kegiatan 2: Membuat Website

Membuat website sederhana dengan menerapkan HTML dan CSS.

Kegiatan 3: Project Showcase

Menampilkan hasil project website yang telah dibuat sebagai portofolio.
